# qr-simple

QR-code equipment lookup for mining field operators — scan a code on-site,
see quick info, click through to fuller documentation. See
[CONTEXT.md](CONTEXT.md) for the domain vocabulary and
[GitHub issue #1](https://github.com/tsogtbatjargal/qr-simple/issues/1) for
the full spec.

- **Setting up a dev environment (new machine, or after a devcontainer
  rebuild)?** Start at [docs/getting-started.md](docs/getting-started.md).
- **Continuing development, human or AI agent?** [AGENTS.md](AGENTS.md) tracks
  architecture, what's built, and what's known-missing.
- **Deploying?** See `AGENTS.md`'s Deployment section.

Live: https://qr-simple.fly.dev
