# QR codes are durable, reusable pointers, not one-time tokens

A QR code encodes a stable URL to an Equipment record's ID (`/e/{id}`), generated once at Equipment creation and never regenerated. If a physical label is lost or damaged, the replacement is printed with the *same* ID rather than issuing a new code and retiring the old one. We considered treating each printed label as a one-time-use token (new ID per reprint), which would let us track "this exact physical tag was scanned" as a distinct fact. We rejected that: it adds bookkeeping (which ID is the "current" one for a given piece of Equipment) with no product need behind it — nothing in the current design cares which physical label was scanned, only which Equipment. Reusing the ID also means Retired equipment's old tags keep resolving (showing a retired state) instead of becoming dead links.
